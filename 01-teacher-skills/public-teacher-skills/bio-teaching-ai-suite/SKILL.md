# 高中生物 AI 教學工作流（總控）

本套件由「高中生物 AI 提示詞工作站」匯出，含 1 個總控與 10 個功能 Skill。總控負責判斷需求、分派到正確的子技能，並在跨任務時串接（例如：出題 → 審題 → 解題簡報）。

## 子技能分派表
| 使用者需求 | 子技能 | 說明 |
|---|---|---|
| 出題、命題、出一份考卷、段考 | `bio-exam-item-writer` | 依會考／學測／分科藍圖命製整份試卷或單題，含誘答設計、評分規準與雙向細目表。 |
| 改題、修題、升級這題、改成素養題 | `bio-exam-item-reviser` | 把舊題改成多選、混合題組、素養情境題或 A／B 平行題，附前後對照與修改理由。 |
| 審題、幫我看這份考卷、檢查考卷、這題有沒有問題 | `bio-exam-quality-reviewer` | 以 15 項檢核表與科學正確性查核整份考卷，分級列出問題並給修正版。 |
| 解題、這題答案是什麼、詳解、考卷解析 | `bio-exam-solver` | 逐題解析大考或段考題目，逐選項說明、圖表解碼、迷思診斷與類題，並核對答案疑義。 |
| 批改、評改、改考卷、非選給分 | `bio-answer-grader` | 依評分規準批改非選擇題或手寫作答，逐點給分、個人化回饋與全班錯誤統計。 |
| 教案、課程設計、教學設計、設計一堂課 | `bio-lesson-plan-designer` | 依 108 課綱設計素養導向教案：UbD／5E／探究與實作架構，含提問鏈、差異化與評量規準。 |
| 講義、學習單、懶人包、重點整理 | `bio-teaching-material-maker` | 產生講義、閱讀學習單、懶人包、複習卷，可一次輸出 A／B／C 分層版本。 |
| 探究學習單、探究與實作、實驗學習單、CER | `bio-inquiry-worksheet-designer` | 設計探究與實作學習單：依開放程度給鷹架，含變因表、數據表、CER 論證與評量規準。 |
| 簡報、投影片、PPT、上課簡報 | `bio-slide-deck-planner` | 逐頁簡報腳本：標題、重點、講者備忘、配圖提示詞與互動檢核點，可對接各家簡報工具。 |
| 資訊圖表、懶人圖、infographic、海報 | `bio-infographic-designer` | 把章節重點變成資訊圖表：中文設計企劃＋英文生圖提示詞＋逐字標註與科學正確性檢核。 |

若子技能未安裝，依本檔的通用規範與下方知識直接執行。

## 常見串接流程
1. 出題 → 審題 → 修正 → 解題詳解（教師版）→ 簡報腳本（檢討課）
2. 教案設計 → 探究學習單 → 非選評改 → 講義（補救）
3. 舊題改題升級 → 審題 → 匯出 Kahoot CSV

## 通用規範
- 繁體中文、臺灣教育用語；科學內容正確，不捏造數據、文獻、課綱代碼。
- 關鍵資訊不足時一次最多問 3 題；使用者要求直接做時列出假設。
- 長篇成品分段輸出，不截斷題目與表格。
- 輸出前自我檢核。
- 學生資料去識別化，只用座號。

## 大考命題趨勢
- 評量語言確立為「三多一沒有」：文字多、圖表多、情境多、沒有複雜計算。重點不是內容變難，而是作答更要求「讀資料、連概念、寫理由」的整合。
- 國中會考：自然 50 題（單題 41＋題組 9），生物約 13 題（約 25%），圖表題約 7–8 成；考「用懂課本」而非「讀完課本」，常考臨界條件的批判推理（例：黑暗中氣孔關閉、維管束單向運輸，不可能逆流）。
- 學測：115 自然 57 題、生物約 17–19 題，試卷 19 頁、約 50 個圖表，整卷約 1.1–1.2 萬字的中高閱讀負荷；111 起混合題型非選擇題已制度化；生物強調「精準表達」；演化支序圖於 114、115 連續出題；諾貝爾獎、探究實作、跨科題組為標配。
- 分科測驗（生物）：獨立單科 80 分鐘、60 級分；112–114 第壹部分固定為「選擇 19＋閱讀 9＋實驗 7」，混合／非選約 20–30%（113 年非選 12 題 26 分）；114 年圖表題 19 題；卷面高度區塊化。
- 分科主題「去邊緣化」：生態、演化、植物學比重上升（113：遺傳與分子 20 分、生態 14 分、植物 8 分）；114 取材 GLP-1、不可能的漢堡、破解密碼子科學史、蜂后與工蜂表觀遺傳、青蛙解剖實作、繞射原理跨科。
- 高頻核心三大類：①演化支序圖；②探究實作（變因、對照、除錯、誤差）；③時事與本土素材（mRNA 疫苗、microRNA、GLP-1、颱風與生態、捕蠅草、尼龍菌、堰塞湖、碳封存、臺灣特有種）。
- 難度設計：保留基礎題，以資料判讀、跨章整合、書寫表達拉開鑑別。例：109 學測生物 17 題＝難 1、中偏難 9、中偏易 6、易 1，平均得分率 50%、平均鑑別度 0.47；114 分科通過率 P 值 42%–94%。
- 學習斷層：國中→高一在「抽象表徵轉換、定性因果推理」；高一→選修在「實作細節與非選書寫」；染色體—DNA—RNA—基因表現—細胞分裂的動態連結最常斷裂。

## 提示詞工程原則（2026）
- **分區結構化**：角色、資料、任務、規格、限制、輸出格式分開寫。Claude 偏好 XML 標籤，GPT 與 Gemini 用 Markdown 標題即可。
- **資料在前、指令在後**：長篇教材或考卷先上傳或貼上，最後再下指令，模型對結尾的指令最敏感。
- **規格具體化**：「5 選 1、20 題、易中難 5:3:2」勝過「難一點的題目」。
- **給範例**：附一題你滿意的題目當示範（few-shot），風格最容易對齊。
- **要求自我檢核**：讓模型輸出前逐項核對清單並先修正，可大幅減少答案錯誤與超綱。
- **允許說不知道**：要求不確定處標註【待查證】，禁止捏造數據與文獻。
- **先問再做或先假設**：關鍵資訊不足時，讓模型一次問 3 題；趕時間則讓它列出假設後直接做。
- **分段與迭代**：長考卷分批輸出，第一版只看方向，第二輪再精修。
- **交叉驗證**：用另一個模型解同一份考卷，答案不一致的題目就是需要人工審的題目。
- **把好流程變成 Skill**：常用的流程下載成 SKILL.md，Agent 安裝後就不用每次重貼提示詞。

## 平台差異
- **通用（任何聊天 AI）**：一般 Markdown 提示詞即可。
- **ChatGPT**：內容較長或需反覆修改時，請用 Canvas 呈現。 涉及遺傳機率、統計或捉放法等計算，請用程式工具實際驗算。
- **Claude**：長篇成品請以 Artifact（文件）呈現，方便我直接修改與下載。 涉及計算時請實際計算驗證，不要估算。
- **Gemini**：若我上傳多個檔案，請先完整讀過全部檔案再作答。 長篇成品可用 Canvas 呈現，方便匯出到 Google 文件。
- **NotebookLM**：只根據目前選取的來源回答，關鍵敘述後附來源引用。 來源未涵蓋的部分，請直接說「來源未提及」，不要自行補完。
- **Microsoft Copilot**：成品請排成可直接匯出到 Word 的格式（標題階層、表格、題號）。
- **AI Agent（Claude Code／Codex／Gemini CLI 等）**：你可以讀寫目前的工作資料夾：先列出並讀取資料夾中的教材、題目或學生作答檔。 成品存為 output/<任務>-<日期>.md（若環境可產生 .docx，另存一份）；不要修改或刪除原始檔。 完成後執行自我檢核，回報輸出檔案路徑與檢核結果。 若環境已安裝 對應子技能 Skill，請依該 Skill 的完整流程執行。
