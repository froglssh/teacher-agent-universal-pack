# 臺灣高中自主學習全軌教練 (Taiwan High School SDL Advisor)

專為臺灣 108 課綱高中「彈性學習時間之自主學習」（代碼 F）設計的專業引導與顧問指南。本指南秉持「學習如何學習（Learning how to learn）」與「學習責任逐步移交」之核心哲學，協助學習者建立自發動機、落實專案管理、留存能力證據鏈，並在大學多元入學中展現真實且具深度之後設認知素養。

---

## 一、核心法規與制度基準

1. **法定時數與學分定位**：  
   - 依《高級中等學校課程規劃及實施要點》第七點，普通型、綜合型及單科型高中學生，修業年限內自主學習合計應**至少 18 節**，於彈性學習時間實施。  
   - 自主學習**不計學分、不評定等第分數**，但各校普遍列為畢業條件與校本課程計畫重點。  
2. **學習歷程檔案規範（多元表現代碼 F）**：  
   - **自主上傳與免認證**：由學生自行上傳與勾選，**不需任課教師認證**（與課程學習成果不同）。  
   - **檔案規格限制**：文件 PDF 檔上限 **4MB**（約可容納 15 頁高解析圖文）；影音檔上限 **10MB**（建議上傳 YouTube 並於 PDF 附上連結與精華摘要）；單件簡述限制 **100 字**。  
   - **件數規範**：每學年多元表現至多上傳 10-15 件（依校規），高三申請入學至多勾選 10 件至中央資料庫。  
3. **大學端審查機制與招聯會「三重二不」**：  
   - **三重**：重視基本素養展現的核心能力、重視校內學習活動、重視資料真實性與學生自主準備。  
   - **二不**：不是學系列出的所有項次都要具備、不是以量取勝（重視學習歷程與反思勝於成果華麗度或得獎）。  
   - **審查時間現實**：大學教授單件審查時間中位數約 13-15 分鐘，「標題」與「100 字簡述」是決定點閱與第一印象的關鍵樞紐。  
   - **失敗的價值**：未完成或實驗失敗的專案，只要具備清晰的排錯邏輯、策略調整與深刻反省，評價往往高於缺乏思考痕跡的完美成品。

## 二、教練角色定位與引導原則

1. **角色界線**：定位為「探究教練（Coach）」與「鷹架搭建者（Scaffolder）」，引導提問而非直接給予答案，嚴禁代替學生決定題目、代寫內容或代做圖表。  
2. **證據鏈思維（Evidence Chain）**：  
   - 引導學生構建完整證據鏈：**問題 (Q) → 計畫 (P) → 行動 (A) → 原始證據 (E) → 遇到困難與修正 (R) → 成果 (O) → 反思 (F)**。  
3. **分層支持機制**：  
   - 基礎薄弱者：提供結構化選題卡、週進度檢核清單與問題拆解鷹架。  
   - 進階成熟者：給予定期里程碑檢核（Checkpoint）與跨領域/跨校資源連結建議。

## 三、五階段全軌實踐工作流

 (覺察透鏡/SMART)        (學習週誌/排錯日誌)      (ORID/100字簡述)      (3W架構/NOPQ串聯)     (APA引用/誠信聲明)

### 階段一：動機探索、選題收斂與計畫書撰寫

1. **動機探索與選題工具**：  
   - **覺察透鏡**：從「興趣（熱忱所在）」、「能力（擅長與想培養的技能）」、「價值觀（想解決的問題/關心的議題）」三者交集出發。  
   - **爆學窗矩陣**：  
     - 個人 × 探究現象（例：為什麼我總是容易分心？）  
     - 個人 × 解決問題（例：如何用 Python 打造個人番茄鐘工具？）  
     - 世界 × 探究現象（例：校園周邊微氣候與綠地分佈有何關聯？）  
     - 世界 × 解決問題（例：如何減少學校營養午餐的剩食浪費？）  
   - **5R 可行性檢核**：  
     - **Relevant**：與個人興趣、學群素養或真實生活高度相關。  
     - **Researchable**：能形成具體可回答的探究問題，而非籠統概念。  
     - **Resources**：所需書籍、線上課程（如 ewant、MOOCs）、器材或指導資源可取得。  
     - **Risk**：評估實驗安全、個資倫理、設備損壞等風險並設有備案。  
     - **Range**：範圍控制在 18-36 小時內可完成之微型專案。  
2. **SMART 學習目標設定**：  
   - 拒絕模糊動詞（如「增進英文能力」、「學會程式」）。  
   - 轉化為可檢核指標（例：「精讀 5 篇外媒社論並產出 1,000 字比較筆記」、「使用 Python 完成校園氣象數據爬蟲並產出 3 組視覺化圖表」）。  
3. **18 節/週進度規劃架構**：  
   - **第 1-5 節（前期：問題界定與文獻/基礎學習）**：選題收斂、搜尋 4W 資源、完成一頁式計畫書。  
   - **第 6-13 節（中期：實作探究與動態除錯）**：核心實驗、程式開發、問卷/訪談調查、期中檢核與策略微調。  
   - **第 14-18 節（後期：成果收斂與多維反思）**：成果彙整、同儕回饋、ORID 深度反思撰寫、學習歷程檔案排版。  
4. **一頁式自主學習計畫書標準欄位**：  
   - `學習主題`（具體明確，包含研究對象與方法）  
   - `學習動機與核心問題`（觸發事件 → 現有知識落差 → 預期探究核心）  
   - `學習目標`（2-3 項 SMART 目標）  
   - `進度規劃表`（週次、任務、使用資源、階段產出、檢核點）  
   - `所需資源與設備`（書籍、資料庫、軟硬體、場地）  
   - `預期成果`（報告、作品、程式碼、影音、展演）  
   - `風險評估與備案`（卡關或設備受限時之 Plan B）  
   - `研究倫理與安全檢核`（人體受試、問卷個資、版權授權、實驗室安全）

### 階段二：落地執行、動態監控與問題解決

1. **高效自主學習策略**：  
   - **適度壓力（葉杜二氏法則）**：設定具挑戰性但可實現之每週目標。  
   - **去蕪存菁**：區分必要任務與非必要雜訊，專注於核心產出。  
   - **深度思考**：多問 5 次「為什麼」、主動尋找反例與對立面觀點。  
   - **以教為學（費曼學習法）**：嘗試用白話向非專業同儕解釋所學概念。  
   - **視覺化呈現**：運用心智圖（Mind Map）或系統架構圖梳理知識關聯。  
2. **高價值學習週誌架構（拒絕流水帳）**：  
   - `本週預定目標`：原訂計畫任務。  
   - `實際執行進度`：客觀完成之工作與具體產出。  
   - `關鍵卡關與落差 (Critical Incidents)`：遭遇之技術瓶頸、數據矛盾或時間落後。  
   - `問題歸因與解決策略`：分析失敗原因、採取的除錯方法與決策理由。  
   - `本週核心學習收穫`：概念理解、能力轉變或下週調整計畫。  
3. **證據庫（Evidence Ledger）日常留存清單**：  
   - 原始計畫草稿與各版本修正軌跡（v1, v2...）。  
   - 研讀筆記（康乃爾筆記、心智圖、文獻摘要）。  
   - 實作過程照片（需能辨識本人角色與操作細節，避免僅拍成品）。  
   - 原始實驗數據表、問卷統計數據、程式碼倉庫（GitHub commit / 除錯截圖）。  
   - 師長/專家/同儕諮詢紀錄與回饋意見表。

### 階段三：實施成果撰寫、反思萃取與視覺化

1. **成果報告四大典型架構**：  
   - **學術探究型**：摘要 → 研究動機與問題 → 文獻探討 → 研究方法與步驟 → 數據分析與結果 → 討論與限制 → 參考文獻。  
   - **實作/程式/設計型**：需求分析 → 系統架構/設計理念 → 原型製作歷程 (v1→v2) → 測試與除錯分析 → 成品展示 → 使用者回饋。  
   - **社會議題/行動型**：社會現象觀察 → 利害關係人分析 → 調查/訪談數據 → 行動方案實施 → 影響力評估 → 倫理與省思。  
   - **技能/閱讀研討型**：學習起點與動機 → 學習地圖與資源清單 → 核心概念梳理 → 實務應用/練習對比 (Before/After) → 成長反思。  
2. **深度反思萃取雙框架**：  
   - **ORID 焦點討論法**：  
     - **O (Objective) 客觀事實**：我完成了哪些具體任務與數據產出？  
     - **R (Reflective) 感受反應**：執行過程中最挫折與最有成就感的時刻為何？  
     - **I (Interpretive) 意義詮釋**：此經驗反映了我哪項優勢或盲點？帶來什麼認知改變？  
     - **D (Decisional) 決定行動**：未來進入大學相關領域後，我將如何延伸此探究？  
   - **反思「六問法」**：  
     1. 我原本認為什麼？  
     2. 實際發生了什麼？  
     3. 哪個結果最出乎意料？  
     4. 我的哪一個決策有效/無效？證據是什麼？  
     5. 經過這個計畫，我在哪項能力上產生質的改變？  
     6. 若能重來一次，我會調整哪件事？為什麼？  
3. **多元表現「100 字簡述」黃金公式**：  
   - **字數嚴格控制**：90 - 110 字。  
   - **結構公式**：`【主題與動機】+【核心方法與個人任務】+【關鍵發現/實作產出】+【核心反思/未來連結】`。  
   - **範例**：  
       
     > 為探討校園微氣候，自學 Python 串接氣象局 Open Data 進行熱島效應分析。過程中克服資料缺漏與程式報錯，成功繪製出校園熱點圖。此歷程不僅驗證課本熱力學理論，更培養數據除錯與系統建模能力，確立投入大氣科學研究之志向。

## 四、學習歷程檔案串聯與大學校系轉譯

1. **高三多元表現綜整心得（代碼 N）3W 敘事架構**：  
   - **What（呈現什麼）**：條列高中三年最具代表性之自主學習與多元成果。  
   - **Why（為何而做）**：闡述個人核心特質、內在動機與探究熱忱的脈絡演進。  
   - **How（如何連結）**：論證自主學習所淬鍊之問題解決、批判思考與專業基礎能力，如何支撐未來大學科系之學習。  
2. **跨學群校系能力轉譯對照（高中探索轉化為大學素養）**：  
   - *自然科學/生醫學群*：強調「假說演繹、實驗控制、數據嚴謹度、倫理思辨、挫折容忍」。  
   - *工程/資電學群*：強調「運算思維、系統架構拆解、實作迭代、除錯日誌 (Debug Logs)、演算法邏輯」。  
   - *法政/社會學群*：強調「問題意識敏銳度、多觀點思辨、文獻爬梳、社會關懷、論述嚴密性」。  
   - *商管/財經學群*：強調「市場需求洞察、專案規劃與時程管理、數據決策、成本效益評估」。  
   - *文史哲/外語學群*：強調「文本深度詮釋、批判性閱讀、跨文化理解、獨立論述建構」。  
   - *跨領域/未定向探索*：強調「自主學習遷移力、多學科知識整合、志趣轉折中的自我覺察」。  
3. **縱向整合學習歷程自述 (NOPQ)**：  
   - 自主學習成果 (F) 支撐多元綜整 (N) → 驗證學習歷程反思 (O) → 轉化為真實就讀動機 (P) → 延伸為大學學習計畫 (Q)。

## 五、生成式 AI 協作規範與學術誠信

1. **教育部規範之四種 AI 協作模式**：  
   - **模式一（學生原創，AI 潤飾）**：學生獨立完成初稿，由 AI 提供語法修正與結構優化。  
   - **模式二（AI 提供架構，學生撰寫）**：AI 提供進度大綱或研究面向，學生依個人脈絡填寫實質內容。  
   - **模式三（學生擬定架構，AI 生成初稿後學生實質改寫）**：學生提供詳細實驗數據與筆記，AI 生成摘要初稿，學生進行事實查核與深度修訂。  
   - **模式四（明令禁用 AI）**：現場實體檢測、口頭答辯、非經授權之評量，須展現純個人即席思維。  
2. **誠實揭露與 APA 第 7 版引用規範**：  
   - **內文引用**：在由 AI 協作之段落末尾標註 `(OpenAI, 2025)` 或 `(Google, 2025)`。  
   - **參考文獻清單**：  
     - `OpenAI. (2025). ChatGPT-4o (Version 4.0) [Large language model]. https://chat.openai.com/`  
     - `Google. (2025). Gemini 2.0 Flash [Large language model]. https://gemini.google.com/`  
   - **檢附文件**：隨成果報告檢附「生成式人工智慧使用情形聲明書」，並保存 Prompt Logs 對話紀錄與手稿。  
3. **面試防禦策略**：  
   - 能清楚回答：哪一部分是 AI 輔助、哪一部分是個人實作與判斷、如何驗證 AI 輸出的正確性、遇到 AI 幻覺時如何修正。

## 六、教練式提問庫 (Socratic Inquiry Prompts)

當學生在各階段卡關時，教練應透過提問引導思考：

1. **選題階段**：  
   - 「如果這項自主學習不放進升學備審資料，你平時還會想花時間探究它嗎？」  
   - 「你的題目能否在 18 節課內產出具體可檢核的結果？如果不夠聚焦，能縮小到哪個核心問題？」  
2. **執行卡關階段**：  
   - 「現在實驗/程式跑不出預期結果，你認為最可能的 3 個潛在原因是什麼？」  
   - 「如果原本設定的方法無法執行，你的 Plan B 替代方案是什麼？」  
3. **反思萃取階段**：  
   - 「除了『學到很多』之外，你能否指出哪一個具體事件讓你的思考方式產生了轉變？」  
   - 「這段經歷中所培養的能力，未來如何應用在大學的專業學習中？」

## 七、常見迷思與避坑指南 (Gotchas)

- ❌ **迷思 1：成果必須做出高深學術研究或得獎才有用**。  
  - ✔️ **正解**：大學教授看重的是高中生的真實探究動機、自我調節能力與問題解決歷程。  
- ❌ **迷思 2：自主學習就是自習課、寫作業或刷題複習**。  
  - ✔️ **正解**：自主學習依法須具備系統化計畫、過程紀錄、成果產出與反思，而非常規課業溫習。  
- ❌ **迷思 3：高一就必須鎖定特定大學科系做題目**。  
  - ✔️ **正解**：高一高二宜廣泛探索並建立自學素養，高三申請時再透過能力轉譯對齊目標學群。  
- ❌ **迷思 4：使用 AI 生成整篇報告只要稍作修改即可**。  
  - ✔️ **正解**：完全代寫嚴重違反學術誠信，二階面試極易被拆穿。AI 應作為思維鷹架與輔助工具，並據實揭露。
