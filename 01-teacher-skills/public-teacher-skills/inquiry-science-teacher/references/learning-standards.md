# 108 課綱自然科學探究與實作：學習表現代碼完整對照表

## 代碼系統說明

學習表現代碼結構：`[子項]-[學習階段]-[流水號]`

- **子項代碼**：探究能力（思考智能 t、問題解決 p）× 科學態度（a）
- **學習階段**：Ⅴc＝高中必修、Ⅴa＝高中加深加廣選修

---

## 高中必修（第五學習階段）學習表現

### 探究能力－思考智能（t）

| 代碼 | 能力說明 |
|------|----------|
| `ti-Ⅴc-1` | 能依據觀察或資料，想像可能的原因與結果，並能以創新的思維，發想各種可行的假設或解決方法 |
| `tr-Ⅴc-1` | 能運用科學知識、科學概念或科學方法，進行思辨分析，並提出自己的見解 |
| `tc-Ⅴc-1` | 能比較不同的論點或証據，評估各種見解的可信度，並能從不同角度批判性地看待自然科學問題 |
| `tm-Ⅴc-1` | 能依據科學概念或原理，透過思考或合作討論，嘗試建立模型，以描述科學現象或解決問題 |

### 探究能力－問題解決（p）

| 代碼 | 能力說明 |
|------|----------|
| `po-Ⅴc-1` | 能從學習活動、日常經驗及科技運用、自然環境、書刊及網路媒體中察覺問題 |
| `po-Ⅴc-2` | 能依據觀察、蒐集資料、閱讀或討論等，提出適合科學探究的問題（或假說） |
| `pe-Ⅴc-1` | 能辨明多個自變項與應變項，計劃適當的觀察、測試方法，並預測活動可能的結果 |
| `pe-Ⅴc-2` | 能正確、安全的操作適合學習階段的物品、器材儀器、科技設備及資源，並能進行質性觀察或數值量測 |
| `pa-Ⅴc-1` | 能運用思考智能、製作圖表、使用資訊及數學等方法，有效整理資訊或數據 |
| `pa-Ⅴc-2` | 能依據資訊或數據，提出結論或解釋，並與他人的結論或解釋相互比對，以確認結論 |
| `pc-Ⅴc-1` | 能理解探究過程和結果，提出較完整的疑問或意見，並能反思探究的過程，提出改善方案 |
| `pc-Ⅴc-2` | 能利用口語、文字、圖表、模型等，表達探究的過程與結果，並選擇合適的發表方式 |

### 科學的態度與本質（a）

| 代碼 | 能力說明 |
|------|----------|
| `ai-Ⅴc-1` | 培養對科學探究的興趣，並能積極主動的進行科學探究 |
| `ah-Ⅴc-1` | 養成應用科學思考與探究的習慣，以理性積極的態度面對自然科學問題 |
| `an-Ⅴc-1` | 了解科學本質，認識科學知識的特性（暫時性、可修正性、以證據為基礎） |

---

## 高中加深加廣選修學習表現（Ⅴa）

代碼結構相同，將 `Ⅴc` 替換為 `Ⅴa`，能力要求更高、更獨立。

關鍵差異：
- `po-Ⅴa-2`：能提出與**學術探索**相關的關鍵問題，而非只限日常情境
- `pe-Ⅴa-1`：能在**有限指導下獨立規劃**最佳化的探究活動
- `pa-Ⅴa-2`：能從數據中形成**新知識、因果關係**，並進一步發現新問題
