📚 108 課綱生物與科學教學技能實用語法

技能名稱 主要能力 老師日常對話範例
素養導向命題
bio-exam-item-writer		 命製學測、分科、段考單選、多選、題組與實驗混合題。 「請依高一生物遺傳章節，命製一題探究導向的題組，含 CER 評分規準與誘答選項。」
試卷審題檢核
bio-exam-quality-reviewer		 以 15 項大考檢核標準，嚴審科學正確性、超綱與選項多解。 「幫我檢查這份高三第一次段考題目，有沒有超綱、歧義或選項有暗示線索的問題？」
非選題 CER 評改
bio-answer-grader		 以主張-證據-推論規準評改學生文字或手寫掃描卷。 「請根據這份評分規準，批改這 3 份學生的非選題作答，逐點給分並指出迷思概念。」
探究實作學習單
bio-inquiry-worksheet		 設計探究四階段鷹架學習單、變因控制表與互評規準。 「請幫我設計一份光合作用反應速率探究實驗學習單，要有變因設計表與誤差分析。」
國寫作文教練
guoxie-writing-coach		 學測國寫知性情意審題、擬大綱、名句庫與高分範文。 「請解析這篇知性題作文題目，給學生起承轉合的大綱引導，並寫一篇示範下水文。」
課程諮詢與選課輔導
course-counselor-assistant		 108課綱適性選課、數A/數B抉擇、加深加廣搭配、18學群與Collego對照、116多元入學與學習歷程「三重二不」轉譯。 「學生想讀資工但高一數學在及格邊緣，請幫我分析選數A或數B的利弊與補救路徑，並產出諮詢紀錄表。」
學習歷程檔案優化
learning-portfolio-helper		 提煉課程學習成果亮點、重構 100 字簡述、梳理突破困境歷程與模擬提問。 「請幫我看這位學生的高一探究學習成果草稿，幫他提煉核心亮點並精修 100 字簡述！」
升學備審與面試顧問
college_admissions_coach		 4F/ORID學習歷程反思、200字綜整3大黃金模板、跨科系學檔轉向、STAR自傳、NOPQ三段讀書計畫與MMI多站迷你面試。 「請針對這份目標醫學系的自傳草稿進行教授紅區檢查，並給予 3 個情境倫理與邏輯思辨的 MMI 模擬面試題。」
自主學習計畫與成果
taiwan-hs-sdl-advisor		 指導 18 週自主學習計畫擬定、反思週誌引導、成果報告書（代碼 F）與 AI 誠信聲明。 「學生想在自主學習做 Python 爬蟲與資料分析，請幫忙擬定 18 週進度架構與反思指引。」
簡報企劃設計
universal-presentation		 將長文教材自動轉換為結構清晰的逐頁簡報大綱與講稿。 「把這篇免疫反應講義，轉成 8 頁教學簡報腳本，每頁都要有核心概念與提問。」

老師常見問題與避坑指南（安全防護）

資安第一、保護隱私！請老師們安心使用：

Q1：申請這些 API 會不會被扣款收費？需要綁信用卡嗎？

答：完全不會！100% 免費！
本教學所引導的所有平台（交通部 TDX、Duffel 航空、Google Cloud）皆具備極為龐大的免費調用額度。老師個人查詢公車、機票或行程，免費額度根本扣不完，且**申請過程不需要輸入任何信用卡號碼**，安全無虞。

Q2：我的個人資料或考卷會不會外流給第三方？

答：絕對不會！
所有 API 都是您在官方平台「自己註冊的專屬私有金鑰」，通訊只在您的電腦與官方伺服器之間進行，絕不會經過任何未知的第三方中繼伺服器，嚴格保護學校與個人隱私。

⚠️ 重大避坑指南：Google 地圖請認明「Routes API」！

Google 正在全面改版路線規劃系統。在 Google Cloud 服務庫啟用時，請務必搜尋並啟用 Routes API 與 Places API (New)。
千萬不要選到舊版的 Directions API，否則會出現 legacy API not enabled 錯誤！本套件已全面適配新版 Routes API，開通後立即可用。
